- M-01: system use-case diagram (DOT and PlantUML).
- M-02: student practice activity.
- M-03: lecturer booking activity.
- M-04: facility-staff decision activity.
- M-05: booking state machine.
- M-06: equipment lifecycle.
- M-07: resource state machine.
- M-08: hazard cause tree.

The legacy `M-07_login_activity.puml` was intentionally excluded because it conflicts with current model M-07. PNG renderings are stored separately in `03_UML/Images/`. This is a draft package; verify source renderings against the corresponding images before final submission.
